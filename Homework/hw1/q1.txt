Q5:
    input embedding: 65536 * 8192 = 536,870,912
    per-layer qkv and attention: 4 * 8192 * 32 * 256 = 268,435,456
    per-layer MLP:
        let the two matrices be W1 and W2:
            W1 = 4 * 8192 * 8192 = 268,435,456
            W2 = W1 = 268,435,456
    per-layer total = qkv + attention + MLP = 3 * 268,435,456 = 805,306,368
    for 64 layers: 64 * 805,306,368 = 51,539,607,552

    therefore, total number of parameters = 51,539,607,552 + 536,870,912 = 52,076,478,464;
    total memory consumption = 52,076,478,464 * 2 bytes = 97 GB.
